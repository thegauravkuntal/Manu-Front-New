# DHIPL WEBSITE REQUIREMENT #

✅ Admin Panel me SEO ke liye 
🔹 A. Page-Level SEO Control (Har Page ke liye)

Hamare har page ke liye ye edit karne ka option milna chahiye:

Meta Title (Dynamic) length 65 Characters tak honi chaiye
Meta Description length 155 characters tak honi chaiye
Meta Keywords 
URL Slug Edit Option
Canonical URL (Auto Generated)
Open Graph Tags (og:title, og:description, og:image)
Schema Markup Add/Edit Option (JSON-LD)
Breadcrumb Edit Option
H1 Tag Editable
All Image Alt Text Editable hona chaiye
Internal Linking Option editable chaiye
Image size admin panel me Dikhana Chaiye har pages me
Image ka size 100Kb se uppar nhi hona chaiye
website ke home page aur services pages me FAQ bhi hona chaiye

Note:- 1. Aur jo bhi website me cards bante hai uska description me kitne characters hone chaiye ye bhi mention karo aur koi limit nhi lagani.
2. Sabhi website me Click Analytics bhi hona chaiye sabhi social media and call, Whatsup Button ka.
3. Website me Admin pannel login karne ka Header me hona chaiye.
4. Sabhi pages ke banner ka size bhi mention karna hai.
5. Website me header, footer and countact us jisme location mail id aur phone number sab editable hona chaiye. 
6. Advance seo me Head code aur Body code dalne ka option hona chaiye.
7. Social media ke sabhi link editable hona chaiye.
8. Webite me agr Carrer page hai to vo bhi editable hona chaiye.
9. H1 website ke har pages ka 1 hi hona chaiye aur vo bhi editable 
10. 404 page bhi bana kar dena hai.


👉 Ye sab dynamic hona chahiye, hardcoded nahi.
